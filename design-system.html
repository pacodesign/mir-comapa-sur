Badges de estado y nivel

Spec canónica única: 10px / 700 / padding 3px 9px / dot ::before 5×5px. No existe otra variante. Si un badge aparece con tamaño, peso o padding distintos en alguna pantalla, es un error que debe corregirse con este spec.

Navegación lateral

El sidebar es idéntico en estructura y estilos en todas las páginas. La única diferencia semántica es el color del ítem activo: maroon para Enlace/Administrador, azul (--color-info) para Revisor. Se implementa con la clase .sidebar--revisor en el elemento .sidebar.
